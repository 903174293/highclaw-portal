title: Memory system
description: SQLite-native hybrid search, embeddings, and hygiene — no mandatory external vector DB.
---

HighClaw implements memory **in Go** with **no required** Pinecone, Elasticsearch, LangChain stack, or Redis for core operations. One SQLite file can power keyword + vector hybrid search.

## Engine

Uses **modernc.org/sqlite** (pure Go, no CGO) for in-process queries — fast cross-compile and low latency vs spawning `sqlite3` CLI.

| Approach | Typical latency | Notes |
| --- | --- | --- |
| Old `os/exec` sqlite3 CLI | ~5–15 ms | Fork per query |
| **modernc.org/sqlite (current)** | **~20–250 µs** | Pure Go |
| CGO mattn/sqlite3 | ~10–100 µs | Needs C toolchain |

## Capabilities (summary)

| Layer | What it does |
| --- | --- |
| Hybrid search | FTS5 BM25 + vector cosine, weighted merge |
| FTS5 `content=` | Triggers keep index in sync, no duplicate bodies |
| BM25 normalization | Scores in \[0,1\] for stable ranking |
| CJK fallback | FTS5 → LIKE when needed |
| Vectors | Embeddings as BLOB, cosine in-process |
| Embedding provider | OpenAI-compatible or `noop` |
| Batch embed | `embedBatch()` — large batches for reindex |
| LRU cache | `embedding_cache` table |
| Chunking | Heading-aware Markdown splitter |
| Hygiene | Archive, purge, retention, throttles |
| Session tags | `session_key`, `channel`, `sender` on entries |
| CLI | `memory search|get|list|status|sync|reset` |

## Example configuration

```yaml
memory:
  backend: "sqlite"
  autoSave: true
  hygieneEnabled: true
  archiveAfterDays: 7
  purgeAfterDays: 30
  conversationRetentionDays: 30
  embeddingProvider: "openai"
  embeddingModel: "text-embedding-3-small"
  embeddingDimensions: 1536
  vectorWeight: 0.7
  keywordWeight: 0.3
  embeddingCacheSize: 10000
  chunkMaxTokens: 512
```

### Field reference

| Key | Values / notes |
| --- | --- |
| `backend` | `sqlite`（默认）、`markdown`、`none` |
| `autoSave` | 是否自动持久化对话记忆 |
| `hygieneEnabled` | 是否启用归档/清理 |
| `archiveAfterDays` | N 天后归档到冷存储 |
| `purgeAfterDays` | N 天后删除 |
| `conversationRetentionDays` | 会话记忆保留天数 |
| `embeddingProvider` | `openai` 启用向量语义检索；`none` 仅关键词（需在 `agent.providers.openai` 配好 Key） |
| `embeddingModel` / `embeddingDimensions` | 嵌入模型与维度 |
| `vectorWeight` / `keywordWeight` | 混合检索中向量与关键词权重 |
| `embeddingCacheSize` | SQLite 中嵌入 LRU 缓存条数 |
| `chunkMaxTokens` | 分块最大 token 数 |

## CLI examples

```bash
highclaw memory search "architecture"
highclaw memory get user_msg_abc123
highclaw memory list --category conversation --limit 10
highclaw memory status
highclaw memory sync
```
