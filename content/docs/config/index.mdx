---

HighClaw reads `~/.highclaw/config.yaml` at startup. Run `highclaw onboard` to generate a starter config, or copy the full template:

```bash
cp config-default.yaml ~/.highclaw/config.yaml
```

## Environment variable overrides

Environment variables take **higher** priority than file values:

| Variable | Overrides |
|---|---|
| `HIGHCLAW_CONFIG` | Config file path |
| `TELEGRAM_BOT_TOKEN` | `channels.telegram.botToken` |
| `DISCORD_BOT_TOKEN` | `channels.discord.token` |
| `SLACK_BOT_TOKEN` | `channels.slack.botToken` |
| `SLACK_APP_TOKEN` | `channels.slack.appToken` |
| `ANTHROPIC_API_KEY` | `agent.providers.anthropic.apiKey` |
| `OPENAI_API_KEY` | `agent.providers.openai.apiKey` |
