Pattern: `highclaw <command> [subcommand] [flags]`. Full list: 60+ commands — this page covers the most common; [part 2](/docs/commands-advanced) covers ops, cron, plugins, migration, etc.

## Setup & onboarding

| Command | Description |
| --- | --- |
| `highclaw onboard --api-key … --provider …` | Non-interactive setup |
| `highclaw onboard --interactive` | Full wizard |
| `highclaw onboard --channels-only` | Channels + allowlists only |
| `highclaw config show` | Print config |
| `highclaw config get <key>` | One value |
| `highclaw config set <key> <value>` | Set value |
| `highclaw config validate` | Validate file |

## Agent & chat

| Command | Description |
| --- | --- |
| `highclaw agent` | Interactive chat |
| `highclaw agent -m "…"` | One shot |
| `highclaw agent -m "…" --session <key>` | Use session |
| `highclaw agent -l` | Continue latest session |
| `highclaw agent rpc` | JSON stdin/stdout RPC |
| `highclaw message "…"` | Shortcut one-shot |
| `highclaw tui` | Terminal UI |

## Gateway & daemon

| Command | Description |
| --- | --- |
| `highclaw gateway` | HTTP + WebSocket gateway |
| `highclaw gateway --port <n>` | Custom port |
| `highclaw gateway --port 0` | Random port |
| `highclaw daemon` | Autonomous runtime |
| `highclaw daemon install\|start\|stop\|status\|uninstall` | Service lifecycle |
| `highclaw service …` | Alias of `daemon` |
