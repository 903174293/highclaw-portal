## Cron (gateway must run)

| Command | Description |
| --- | --- |
| `highclaw cron list` | Scheduled tasks |
| `highclaw cron add\|edit\|delete` | Manage tasks |
| `highclaw cron enable\|disable <id>` | Toggle |
| `highclaw cron status` | Scheduler status |
| `highclaw cron runs <id>` | History |
| `highclaw cron trigger <id>` | Manual run |

`main` agent can manage all jobs; sub-agents only their own.
