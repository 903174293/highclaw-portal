HighClaw uses a **unified local session store** (`~/.highclaw/sessions`) shared by CLI, TUI, and all channels.

## Capabilities

| Feature | Description |
| --- | --- |
| Auto-create | Each `highclaw agent -m "..."` can create a new session |
| Multi-turn resume | `--session <key>` resumes with full history |
| TUI | Sidebar lists CLI + TUI sessions |
| Persistence | JSON files under `~/.highclaw/sessions/` |
| Cleanup | `sessions prune` (default ~30 days, max count) |
| Channel binding | External channels bind via routing |
| Memory tags | Entries include `session_key` |

## Session key format

```
agent:{agentId}:{sessionName}
```

Examples:

- `agent:main:cli-1234567890` — CLI one-shot
- `agent:main:session-42601` — TUI session
- `agent:main:main` — Default for external channels

## CLI cheat sheet

```bash
highclaw agent -m "Hello!"
highclaw agent -m "Continue" --session agent:main:cli-1234567890

highclaw sessions list
highclaw sessions get <key>
highclaw sessions current
highclaw sessions switch <key>
highclaw sessions reset <key>
highclaw sessions delete <key>
highclaw sessions prune
highclaw sessions prune --max-age 7
highclaw sessions prune --max-count 100

highclaw sessions bindings
highclaw sessions bind <ch> <conv> <key>
highclaw sessions unbind <ch> <conv>
```

## DM scope (routing)

| `dmScope` | Session key pattern | Use case |
| --- | --- | --- |
| `main` | `agent:main:main` | All DMs share one session |
| `per-peer` | `agent:main:direct:<peerId>` | Per user, merged across channels |
| `per-channel-peer` | `agent:main:<channel>:direct:<peerId>` | **Recommended** — per user/channel |
| `per-account-channel-peer` | `agent:main:<channel>:<accountId>:direct:<peerId>` | Multi-bot isolation |

**Groups** route by group id: `agent:main:<channel>:<peerKind>:<groupId>`.

### Config snippet (`~/.highclaw/config.yaml`)

```yaml
session:
  scope: per-sender
  dmScope: per-channel-peer
  mainKey: main
  identityLinks:
    alice:
      - telegram:alice_tg
      - whatsapp:+1234567890
```

### Full `session` reference

**Scope** — `per-sender`（每发送者独立，推荐）或 `global`（全员共享一会话）。

**History** — `historyLimit`：每次请求发给模型的最近消息条数（L1 活动窗口）。默认约 32；过小易「失忆」，过大耗 token。

**Identity links** — 跨渠道合并同一用户（字符串键与列表项均可带引号）：

```yaml
session:
  identityLinks:
    "user-alice":
      - "telegram:12345678"
      - "discord:987654321"
```

**Workspace isolation** — `isolation`: `shared`（共享 workspace）、`agent`（`~/.highclaw/workspace/agents/{agentId}/`）、`session`（按会话哈希隔离）。`cleanupAfterDays` 清理过期会话 workspace。

**Three-layer memory**（防上下文丢失）：

- **L1**：最近 `historyLimit` 条原文进模型
- **L2**：结构化要点（本地规则，无 LLM、无 token）
- **L3**：L2 超预算时 LLM 压缩摘要（很少触发）

```yaml
session:
  memory:
    enabled: false
    notesMaxTokens: 2000
    compactionModel: ""
    compactionReserveTokens: 20000
```

长对话可设 `enabled: true`；L2 无 API 费用，L3 通常在数百轮后才触发。

## TUI keys

| Key | Action |
| --- | --- |
| Tab | Focus sidebar / input |
| ↑ / ↓ | Navigate sessions |
| Enter | Send / open session |
| Ctrl+N | New session |
| Ctrl+L | Clear view |
| Ctrl+R | Reload list |
| Ctrl+C | Quit |

## Slash commands (channels / TUI)

| Command | Description |
| --- | --- |
| `/new`, `/reset` | Fresh session |
| `/session <key>` | Switch session |
| `/sessions` | List sessions |
| `/agent <id>` | Switch agent |
| `/model [provider/model]` | View/override model |
| `/think [level]` | Thinking level |
| `/help`, `/commands` | Help |

## Quick verification

```bash
highclaw agent -m "first"
highclaw agent -m "second"
highclaw sessions list
highclaw tui
```

You should see multiple sessions in the TUI sidebar.
