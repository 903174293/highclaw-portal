**HighClaw** 是快速、轻量、可自主运行的 AI 助手基础设施：随处部署，组件可替换。

> **高性能 · 为速度与可靠性而生 · 100% Go · 与具体厂商解耦**

```
Go 二进制 · 模块化 trait · 22+ 模型提供商 · 可插拔渠道/工具/内存 · 生产级网关
```

## 特性概览

- **高性能** — Go 运行时优化，启动快、长驻稳定。
- **部署成本低** — 单文件即可上边缘、虚拟机或云主机。
- **运维简单** — 不依赖 Node/Python 引导，分钟级装好。
- **默认可靠** — 网关鉴权、内存持久化、渠道安全默认值。
- **跨平台** — macOS / Linux / Windows，amd64 与 arm64。

## 多渠道网关

一个二进制对接多种即时通讯与 Webhook，支持富文本、图片与交互回复。
